# MeowdokuPuzzlePractice

## 프로젝트 목적

Unity / C#을 이용해 퍼즐 게임의 문제 생성 알고리즘을 직접 설계하고 구현하는 연습 프로젝트입니다.

## 주요 규칙

- N×N 크기의 보드
- 각 행에 고양이 1마리 배치
- 각 열에 고양이 1마리 배치
- 고양이 주변 8칸에는 다른 고양이 배치 불가

## 퍼즐 생성 알고리즘

### 1. 고양이 위치 결정

1. 0번째 행부터 마지막 행까지 순서대로 고양이 위치를 무작위로 결정합니다.
2. 배치 과정에서 이후 행에 배치할 수 있는 위치가 없어지는 경우가 발생할 수 있습니다.
3. 이 문제를 해결하기 위해 백트래킹을 적용하여 이전 배치를 되돌리고 다른 위치를 탐색합니다.

### 2. 타일 색상 결정

1. 고양이 위치를 기준으로 상하좌우에 인접한 타일의 색상을 무작위로 결정합니다.
2. 이후 아직 색상이 결정되지 않은 타일은 인접한 타일의 색상 중 하나를 무작위로 결정합니다.

### 3. 퍼즐 검증 (구현 중)

1. 생성된 문제가 풀이 가능한지 확인합니다.
2. 풀이가 여러 개 존재하는지 확인하여 유일해 여부를 검증합니다.

### 4. 문제 폐기 (구현 예정)

풀이가 불가능하거나 유일해를 갖지 않는 경우 해당 문제를 폐기하고 다시 생성합니다.

## 프로젝트 상태

현재 퍼즐 생성 알고리즘을 중심으로 구현 및 검증을 진행하고 있습니다.
